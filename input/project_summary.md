# Project summary and build instructions (from SDLC_Claude_Code_Input.pptx, slide 2)

- Goal: build 8 agents and their skills for an SDLC system for web and mobile apps, run inside VS Code.
- Build Phase 1 first (65 skills), across all agents. Start Phase 2 and 3 only after Phase 1 passes.
- Inputs: text story, user story, Figma, or screenshot. Text-only input gets a PROPOSED UI/UX baseline.
- Human gates: Ready, design approval, Quality GO, release approval. Agents never mark them done.
- Board: kanban.md, updated by A1 at each handoff and committed at each stage.
- Rules: cite sources; missing values become TBD plus an open question; fresh-context check before handoff.
- Stack: GitHub for code, pull requests and CI. React Native or Flutter for mobile; any framework for web.
- Sprint 1 goal: one text story through Phase 1 to a released build.
- Expected output: agent definitions, one SKILL.md per skill, the kanban.md writer, and one test run.
