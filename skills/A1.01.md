# A1.01 kanban.md update

- Agent: A1 Orchestrator
- Skill: kanban.md update
- Phase: 1
- Human gate: No

## Purpose
Moves items between columns in kanban.md when exit criteria are verified; human-gated moves wait for a recorded approver
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. Receive a status event from an agent.
2. Check the exit criteria for the column.
3. Move the item, add a History row, and commit.

## Verification (PROPOSED)
A History row exists for every move.
Rules [R1-R10](../rules/R1-R10.md) also apply.
