# A5.08 Component codegen

- Agent: A5 Developer
- Skill: Component codegen
- Phase: 1
- Human gate: No

## Purpose
Generates components from an approved component spec (baseline or design-derived) using the design tokens
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. Read the approved component spec and tokens.
2. Generate the component.

## Verification (PROPOSED)
No color or spacing value is hardcoded outside the tokens.
Rules [R1-R10](../rules/R1-R10.md) also apply.
