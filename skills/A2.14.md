# A2.14 UX state definition

- Agent: A2 Requirements
- Skill: UX state definition
- Phase: 1
- Human gate: No

## Purpose
Defines loading, empty, error, offline, permission-denied states; unknown states become open questions
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. For each screen, check loading, empty, error, offline, and permission-denied.
2. Define the states the source gives.
3. Log any unknown state as an open question.

## Verification (PROPOSED)
Each screen has all five states or an open question.
Rules [R1-R10](../rules/R1-R10.md) also apply.
