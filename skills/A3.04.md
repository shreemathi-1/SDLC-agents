# A3.04 Minimum UI/UX checklist

- Agent: A3 UI Designer
- Skill: Minimum UI/UX checklist
- Phase: 1
- Human gate: No

## Purpose
Checks the baseline and built UI against the minimum requirements (primary action, states, labels, touch targets, contrast, text scaling, feedback)
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. Check: one primary action, states, labels, touch targets, contrast, text scaling, feedback.
2. Record pass or fail per item.
3. Use the target sizes the source sets; default sizes are PROPOSED.

## Verification (PROPOSED)
Every item is marked pass or fail with evidence.
Rules [R1-R10](../rules/R1-R10.md) also apply.
