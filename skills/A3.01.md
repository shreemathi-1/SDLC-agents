# A3.01 Text-only UX baseline

- Agent: A3 UI Designer
- Skill: Text-only UX baseline
- Phase: 1
- Human gate: No

## Purpose
From the user story text only: user journeys, screen list, navigation map, screen states. Labeled PROPOSED until a human approves
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. Derive user journeys from the story text.
2. List screens and navigation between them.
3. Define screen states and label the output PROPOSED.

## Verification (PROPOSED)
Every screen traces to a story and carries the PROPOSED label.
Rules [R1-R10](../rules/R1-R10.md) also apply.
