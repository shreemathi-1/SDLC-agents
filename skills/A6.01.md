# A6.01 Test plan creation

- Agent: A6 Test Engineer
- Skill: Test plan creation
- Phase: 1
- Human gate: No

## Purpose
Produces test plan per story or release covering scope, risks, environments
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. List scope from the stories.
2. List risks and environments.
3. Name the test types for each story.

## Verification (PROPOSED)
Every acceptance criterion is in scope.
Rules [R1-R10](../rules/R1-R10.md) also apply.
