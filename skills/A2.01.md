# A2.01 Input intake and type detection

- Agent: A2 Requirements
- Skill: Input intake and type detection
- Phase: 1
- Human gate: No

## Purpose
Detects whether input is text, user story, Figma link, Figma screenshot, or mixed; builds an input manifest with source IDs
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. List each input: text, story, Figma link, screenshot.
2. Give each an ID: T-01, SS-01, FIG-01.
3. Write the input manifest with source for each.

## Verification (PROPOSED)
Every input has an ID and a source.
Rules [R1-R10](../rules/R1-R10.md) also apply.
