# A2.02 User story writing

- Agent: A2 Requirements
- Skill: User story writing
- Phase: 1
- Human gate: No

## Purpose
Converts a request into 'As a… I want… so that…' stories with a source reference
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. Read the request text.
2. Write each story as 'As a… I want… so that…'.
3. Cite the source ID on each story.

## Verification (PROPOSED)
Each story cites a source ID.
Rules [R1-R10](../rules/R1-R10.md) also apply.
