# A8.09 Defect fix loop

- Agent: A8 Reviewer & Release
- Skill: Defect fix loop
- Phase: 1
- Human gate: No

## Purpose
Sends findings to developer and re-reviews fixes; stops at a loop limit set in config and escalates to a human
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. Send findings to the developer.
2. Re-review the fix.
3. Stop at the loop limit and escalate to a human.

## Verification (PROPOSED)
Loop count is recorded against the limit. Limit: 3 loops (R6; approved by human in open_questions_answers.md item 1).
