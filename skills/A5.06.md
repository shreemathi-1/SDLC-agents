# A5.06 Bug fixing

- Agent: A5 Developer
- Skill: Bug fixing
- Phase: 1
- Human gate: No

## Purpose
Reproduces a reported bug, identifies root cause, applies a minimal fix
(Source: SDLC_Agent_Skills_Excel.xlsx, via input/phase1_skill_details.csv)

## Steps (PROPOSED, human approves; R10)
1. Reproduce the bug from its steps.
2. Find the root cause.
3. Apply a minimal fix with a test.

## Verification (PROPOSED)
The test fails before the fix and passes after it.
Rules [R1-R10](../rules/R1-R10.md) also apply.
